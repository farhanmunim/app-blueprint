Design language

One system for every web app.

Tokens first, components second. Everything below is built from the same layered CSS tokens, works in light and dark, and re-skins from a single theme.css. Start every new project here.

Usage

Theming a new project

Copy css/ and fonts/ into the new project, then override only what the brand needs in css/theme.css — it loads last and un-layered, so it always wins.

:root { --radius-scale: .75; --space-unit: 3.5px; }
[data-theme="dark"]  { --accent: #7dd3fc; --on-accent: #0b1220; }
[data-theme="light"] { --accent: #0369a1; --on-accent: #ffffff; }

Full guide in THEMING.md. Rules: components use semantic tokens only; no raw colours outside the theme files; light and dark ship together from day one.

About App Blueprint

App Blueprint is an open-source, pixel-perfect web app wireframe that demonstrates a realistic SaaS-style interface — sidebar navigation, data tables, inspector panel, command palette, and a responsive mobile shell. It's a reference implementation and starting point for building production-quality dashboard UIs.

All content is hardcoded placeholder data. "Acme Inc." and the sample records are intentional stand-ins and do not represent a real company.
